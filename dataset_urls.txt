ObsCal external resource register
=================================
Every line below was fetched from this host and its returned content was matched
against the identifier the manuscript prints in its Table 1 / Table S21 row.
Entries are grouped by what the item is, because the access condition differs:
an expression deposit is a data resource, a catalogue number is a material
resource, and a cell-line record is an identifier resolution service.

Nothing in this file is redistributed with the release. The on-chip device
records behind the manuscript's own tables are not deposited by the article and
are not obtainable here; that absence is a property of the study, not of this
link list.
